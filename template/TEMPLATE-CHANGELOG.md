## 0.10.0 — 2026-10-18 — Reports rails: agent-published HTML via GitHub Pages

- New skill `$publish-report` (`template/scripts/skills/publish-report/`, rendered to downstream `.agents/skills/publish-report/`): publishes a static `index.html` folder to the orphan `gh-pages` branch under `reports/<date>-<slug>/` and hands back the public `https://<owner>.github.io/<repo>/reports/<slug>/` URL; unpublish deletes the folder and regenerates the index. Guards per ADR-0002 (`docs/adr/0002-pages-for-agent-reports.md`): ≤10MB payload, `index.html` entry required, UTC-dated slug with collision suffixing, no truncation, no secrets.
- Deploys ship in-template: `template/scripts/pages-reports.yml.tmpl` — stock `deploy-pages` Actions that fires on a `repository_dispatch` of type `pages-reports` (fired by the skill after every publish/unpublish push; a bare `gh-pages` branch carries no workflow file, so a push there alone triggers nothing) with a `push: branches: [gh-pages]` trigger kept for checkouts that do track the file there — plus `template/scripts/build-reports-index.mts.tmpl`, the index generator (`<title>` extraction, HTML-escaped, dated ordering, empty-list page).
- Dogfooded at root: `scripts/build-reports-index.mts` and `.github/workflows/pages-reports.yml` are byte-identical mirrors of the payload; the AGENTS seed gains a `### Reports` pointer; `TEMPLATE-OWNERSHIP.md` and `CONTRIBUTING.md.tmpl` onboarding name the flow.
- One-time enablement per repo: skill step 1 self-serves via `POST /repos/{owner}/{repo}/pages` (build type workflow) when the token has admin, otherwise stops with the Settings path; the same preflight names a missing `origin` remote or an unauthenticated gh with the fix for each.
- Migration: existing downstreams gain 4 files on next sync and see `NOTICE: AGENTS.md seed changed` on this version bump (seed-only, never overwritten) — hand-merge the Reports pointer if wanted. No tokens, no secrets; reports are public-safe only (the index enumerates all slugs).
- Fixture proof (scratch, 2026-10-18): render proof 31 files (27 baseline + 4), bootstrap audit 0 tokens / 0 schooling, downstream token-audit PASS, generator fixture run correct (escaping, fallback, ordering, empty list, usage-exit-1). Live gate on this repo: sample `2026-10-18-q16-gate-sample` published, deployed, verified, and unpublished.

## 0.9.0 — 2026-10-03 — Vision grounding + pasteable next-step prompts in the AGENTS seed

- The AGENTS seed (`template/docs/AGENTS.md.tmpl`, mirrored in this repo's root `AGENTS.md`) gains two `###` sections: **Vision grounding** — before planning or reconciling a feature request, read `docs/VISION.md` first and cite the sections served (`Serves §4 …`), confirming `§8 Non-goals and exclusions` / `§10 Egypt-first edge` don't exclude it; if no section fits, write `OUT OF VISION` and ask before continuing. **Example prompts for next steps** — any next step meant for a different session ends with a fenced block the human can paste into a fresh one: instruction, read-first list, definition of done; sequences in one block, independent steps in separate blocks; same-session work and handoff documents exempt.
- No new tokens and no new files: a repo opts into vision by creating `docs/VISION.md`. Where that file is absent the rule skips itself silently, so existing downstreams are unaffected.
- Migration: existing downstreams see `NOTICE: AGENTS.md seed changed` on next sync (seed-only, never overwritten) — hand-merge the two sections if wanted.

## 0.7.0 — 2026-10-01 — AGENTS.md ownership lift: seed-only + notify

- `AGENTS.md` is project-owned now (seed-only + notify, a fourth state distinct from `protected`): bootstrap seeds it once from `docs/template/AGENTS.md.tmpl`, adopt creates it only when absent, sync never overwrites it when present.
- Loud-notify path: when the seed changes (template version bump) and downstream `AGENTS.md` differs, adopt and sync print `NOTICE: AGENTS.md seed ...` plus a capped line diff and keep the downstream file. Same-version divergence stays silent (`protected`); `LOCAL-EDIT` suppresses repeat NOTICE until the seed version moves. Sync reports these as `noticed` and appends them to `PERSONALIZATION.log.md`; exit stays 0 including `--non-interactive`.
- Recreate rule: sync recreates a missing downstream `AGENTS.md` from the seed, unless `CLAUDE.md` exists (one entrypoint only — then it skips and notices instead, per `setup-matt-pocock-skills` never-create-both rule).
- Grounding guard: `CONTRIBUTING.md` now marks `AGENTS.md` as project-owned entrypoint that should keep its `docs/agents/*` pointers; rendered `token-audit` prints a soft WARNING (not fail) when those pointers are gone.
- Migration: existing diverged `AGENTS.md` files stop getting Yes-gated update prompts immediately; the first NOTICE fires only on the next seed change, not on day one.

## 0.5.0 — 2026-09-20 — Clean-room setup: purge, scripts layout, agent-driven bootstrap

- History restarted here: earlier entries referenced the template's source project and are gone. New projects seeded from this version carry no source-project history.
- No source-project blocklists anywhere: the old residue lists (project name, collaborator handles, domain words, old model id) are deleted from `scripts/bootstrap.mts`, `scripts/adopt.mts`, and the rendered `scripts/token-audit.mts`. Audits check unrendered `{{TOKENS}}` + wording only.
- Layout: `bootstrap.mts`, `adopt.mts`, `sync-template.mts` moved from the repo root to `scripts/` (assumed to have always lived there; no shims). All docs, `package.json` scripts, audit skip-lists, and the updater's META sync follow the new paths. Downstream keeps the updater at `scripts/sync-template.mts`.
- Agent-driven bootstrap: the README's canonical path is a paste-to-agent prompt. Identity inputs (name, slug, org, members, domain) have no placeholder defaults — interactive runs re-prompt, non-interactive runs fail loudly instead of rendering placeholders. Only team size (derived), learning depth, stack, model, and credential var keep defaults.
- Default model is now `opencode/big-pickle` (wizard default, fixture, `.env.example` comment). Credential default stays `OPENCODE_API_KEY`.
- Machine sync record for every project: `scripts/bootstrap.mts` now writes `.template-sync.json` (`{template, version, inputs}`), same shape as adopt. Both writers read the version from the top `## X.Y.Z` line of this changelog, so they can never disagree; `sync-template` reads the record when `--input` is omitted.
- Env setup is copy-only: every doc and log says `cp .sandcastle/.env.example .sandcastle/.env` (never move), and the rendered root `.gitignore` now ignores `.env` plus `.sandcastle/.env`.
- Clean tree: after bootstrap the README instructs `rm -rf .git && git init` plus a fresh initial commit, so the new project starts with no template history. Later releases pull via an explicit `--template <checkout>` path.
- Fixture proof (scratch, 2026-09-20): fixture bootstrap renders 23 files, token-audit PASS (0 tokens, wording clean), wizard + template sources self-deleted, `.template-sync.json` present. Updater no-op round-trip: identical files skip, protected untouched.
