# Decisions (ADRs)

Accepted and superseded hard-to-reverse decisions for the repo live here as one Markdown file per decision (`NNNN-slug.md`). ADRs are immutable once accepted — supersede with a new numbered ADR linking the old one, never rewrite history.

Template blueprints carry their own seed under `template/docs/`; numbered decisions about downstream projects belong to each project, not here.
